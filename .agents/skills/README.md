# Skills (lokal proyek)

Skill khusus proyek money-tracker. Diletakkan di sini agar ikut ke-version
bersama repo (berbeda dengan skill global di `~/workspace/custom-skills/`).

## Konvensi

- Satu skill = satu folder `<nama-skill>/` berisi `SKILL.md`
- Ikuti format SKILL.md yang sama dengan skill global (nama, deskripsi kapan
  dipakai, langkah proses)
- Daftarkan skill baru di bawah ini setelah dibuat
